# チームバレー帳

社会人9人制バレーボールチームのための、練習・戦術・チーム運営アプリです。キャプテンの頭の中にあった練習内容や判断ルールを、メンバー全員が見られる形にまとめています。

## 機能

| タブ | 内容 |
| --- | --- |
| ホーム | 次の大会までのカウントダウン、今月のテーマ、自分の目標と改善ポイント、ポジション別の「まず読むカード」 |
| 戦術 | 配置図（サーブレシーブ／サイド攻撃／センター攻撃）、判断ルール7か条、他の配置パターン、戦術ボード（ディグ：スパイクコース・ブロックの陰が連動／レセプション：担当エリアとお見合いゾーン）。配置図はチームに合わせて編集・場面追加ができる |
| 技術 | 技術カード（症状 → 原因 → 声かけ）。サーブ4種と狙い所の図、スパイクの助走タイミング、トスのコツ |
| 練習 | 人数とテーマから2時間メニューを自動作成、テーマのルーレット、役割別の基礎練 |
| チーム | 名簿（背番号・名前・ポジション・選手登録）、セットごとのオーダーとサーブ順、大会予定、選手ごとの育成メモ（目標・伸ばすところ・改善ポイント・記録）、チーム名とチームカラーの設定 |

## ホーム画面に追加する

GitHub Pages で公開しています：https://issei-cloud.github.io/team-volley-book/

- iPhone：Safari で開き、共有ボタン →「ホーム画面に追加」
- Android：Chrome で開き、「⋮」→「ホーム画面に追加」（「アプリをインストール」と出る場合もあります）

ホーム画面から開くと、ブラウザの枠のない独立したアプリとして動きます。一度開けば電波がなくても使えます。

## データの保存と受け渡し

- 名簿・オーダー・大会予定は、それぞれの端末（ブラウザ）に保存されます。サーバーには送られません。
- メンバーと同じ内容にするときは「チーム」タブ下の「データの受け渡し」で書き出したファイル（または文字）を送り、相手に読み込んでもらいます。
- 読み込むと、同じ選手・予定・オーダーは上書きされ、新しいものは追加されます。
- 選手ごとの育成メモは、初期設定では受け渡しに含まれません。本人だけに渡すときは、選手の育成ページの「この選手の分だけ送る」を使います。

## 構成

- `index.html`：アプリ本体（ビルド不要）
- `manifest.webmanifest`・`icons/`：ホーム画面用の設定とアイコン
- `sw.js`：オフラインでも開けるようにするための仕組み
- このリポジトリにはメンバーのデータは含まれません。

## 個人情報について

名簿には名前以外の個人情報（連絡先・住所など）を入れない方針です。
