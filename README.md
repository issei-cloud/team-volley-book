# チームバレー帳

社会人9人制バレーボールチームのための、練習・戦術・チーム運営アプリです。キャプテンの頭の中にあった練習内容や判断ルールを、メンバー全員が見られる形にまとめています。

## 機能

| タブ | 内容 |
| --- | --- |
| ホーム | 次の大会までのカウントダウン、今月のテーマ、ポジション別の「まず読むカード」 |
| 戦術 | 配置図（サーブレシーブ／サイド攻撃／センター攻撃）、判断ルール7か条 |
| 技術 | 技術カード（症状 → 原因 → 声かけ）。サーブ4種と狙い所の図、スパイクの助走タイミング、トスのコツ |
| 練習 | 人数とテーマから2時間メニューを自動作成、テーマのルーレット、役割別の基礎練 |
| チーム | 名簿（背番号・名前・ポジション・選手登録）、セットごとのオーダーとサーブ順、大会予定 |

## 構成

- `index.html` 1ファイルで動きます。ビルドは不要です。
- 名簿・オーダー・大会予定は、claude.ai のアーティファクトの共有データベース（`db` capability）に保存されます。このリポジトリにはメンバーのデータは含まれません。
- claude.ai の外でファイルを直接開いた場合は、データはそのブラウザの localStorage に保存されます（共有されません）。

## 個人情報について

名簿には名前以外の個人情報（連絡先・住所など）を入れない方針です。
